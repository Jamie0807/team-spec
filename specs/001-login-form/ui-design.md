# UI 设计：登录表单

## 布局

- 桌面端：首屏两栏布局，左侧展示品牌内容，右侧展示登录表单。
- 移动端：单列布局，品牌内容位于表单上方。

## 表单

- 标题：`登录`
- 辅助说明：`使用你的账号进入 Team Spec 工作台。`
- 字段：邮箱和密码。
- 控件：“记住我”复选框、“忘记密码”文本按钮、提交按钮。
- 底部提示：`还没有账号？联系管理员开通。`

## 状态

- 字段错误显示在对应输入框下方。
- 无效字段使用红色边框和 ARIA invalid 状态。
- 提交中禁用提交按钮。
- 模拟登录完成后展示成功提示。

## 审批

UI 设计已在实现前获得用户确认。
