# 数据模型：登录表单

## 登录凭据

- `email`：用户输入的邮箱。
- `password`：用户输入的密码。

校验规则：

- `email` 必填。
- `email` 必须符合基本邮箱格式。
- `password` 必填。
- `password` 至少 8 个字符。

## 表单状态

- `rememberMe`：布尔开关。
- `errors`：字段级校验信息。
- `isSubmitting`：布尔加载状态。
- `successMessage`：模拟成功后显示的提示信息。

状态流转：

1. 空闲：字段可编辑。
2. 校验失败：显示字段错误。
3. 提交中：提交按钮禁用。
4. 成功：显示成功提示。
