# 调研：登录表单

## 决策：使用 React 本地状态

**原因**：表单只需要邮箱、密码、“记住我”、校验错误、加载状态和成功反馈。本地状态足够满足需求，也能保持实现简单。

**备选方案**：未采用表单库，因为该功能不需要 schema 组合、嵌套字段或复杂提交流程。

## 决策：模拟登录提交

**原因**：功能范围排除了真实鉴权接口。短暂延迟可以展示加载和成功状态，同时不依赖后端。

**备选方案**：未接入 API，因为当前仓库没有后端接口契约。

## 决策：只使用 Tailwind CSS

**原因**：项目已经使用 Tailwind CSS，登录页可以通过 utility class 实现，无需新增组件库或 CSS 框架。

**备选方案**：未采用 UI 库，避免为了单个表单引入额外依赖。
