# Team Spec UI 设计

## 输入

- `spec.md`。
- `plan.md`。
- 产物目录。

## 输出

在产物目录写入 `ui-design.md`。

## 执行步骤

1. 识别需要的页面、状态、交互和响应式行为。
2. 遵循当前 React、Vite、TypeScript 和 Tailwind CSS 约定设计。
3. 明确布局、层级、控件、空状态、加载状态和错误状态。
4. 除非需求明确要求其他风格，否则保持界面实用、清晰、面向任务。
5. 将设计提交给用户审批。

## 必须门禁

写入 `ui-design.md` 后必须暂停。用户没有明确批准 UI 设计前，不得进入测试用例生成或编码阶段。

## 完成标准

- UI 行为和视觉结构已经具体到可以实现。
- 已向用户请求人工审批。
