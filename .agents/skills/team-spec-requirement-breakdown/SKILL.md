# Team Spec 需求拆解

## 输入

- `spec.md`。
- 产物目录。

## 输出

拆解结果优先写入 `spec.md` 的用户故事、验收场景和功能需求；如需补充记录，可写入
`requirements-breakdown.md`。

## 执行步骤

1. 读取 `spec.md`。
2. 将工作拆分为用户故事或行为切片。
3. 为每个切片补充可测试的验收标准。
4. 识别依赖关系和执行顺序约束。
5. 标记需要设计、调研或进一步实现细节的切片。

## 完成标准

- 工作已拆成可以独立理解的切片。
- 验收标准可测试。
- `spec.md` 已按优先级列出独立可测试的用户故事。
